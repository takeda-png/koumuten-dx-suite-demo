# 工務店DXスイート(デモ)

住宅会社・工務店向けの業務DXスイートのデモアプリです。単一HTMLで動作します。

- 経営:ダッシュボード(前年比・アラートセンター)/ 実行予算 / 月次報告書(1冊出力)/ 3ヶ年経営計画(目標から必要な棟数・反響・人員を逆算)
- 営業:追客管理(Excelインポート対応)/ 資金計画・FP(返済計画書印刷)/ 見積書 / 補助金情報
- 設計:設計AIプレゼン / 図面アーカイブ(ボツ案DB)/ 仕様決定・変更管理AI(打合せメモ→仕様確定書→変更合意書)
- 工事:ヒヤリハット・クレーム管理(記録→初動→再発防止→仕組み化まで追跡)/ 工程×職人手配(年間一覧+日単位・天気API連動)/ 現場写真・施主週報 / 検査・是正管理(社内・第三者機関・施主検査の指摘と是正)
- 集客:施工事例WORKS / SNS投稿AI(インサイト分析)/ WEB分析(LLMO)/ アフター点検・OB管理
- 基盤:データ連携ハブ / 導入・運用ガイド

※ すべてデモデータです。実在の企業・案件・数値とは関係ありません。
※ 工程表の天気はOpen-Meteo APIの実予報を使用(通信不可時はデモデータに自動切替)。
